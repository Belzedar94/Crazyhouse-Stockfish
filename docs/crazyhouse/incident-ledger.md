## Preventive consequences

- Header compatibility is not runtime evaluator certification.
- Browser timeout, network outage, source failure, compiler failure, and incomplete external review are distinct states.
- A referee is authenticated by source, build, bytes, variant routing, clocks, notation, and result corpus together.
- Requested NNUE mode must remain fail-closed across filename routing; byte compatibility cannot excuse a wrong variant identity.
- Process ownership is established by a recorded supervisor ancestry, never by executable name, command similarity, start time, or perceived idleness.
- A pinned compiler path does not imply a complete build environment; sanitizer leases require an explicit toolchain `PATH` and a persistent captured supervisor.
- A 64-bit compiler executable does not imply Stockfish's 64-bit compile-time profile; product controls must use and record the canonical Makefile architecture contract.
- Internal benchmark options are real route changes and must pass the same apply barrier as external commands.
- Search state may survive a route epoch only for the exact authenticated chess-only Chess960 transition that reproduces pinned upstream behavior; every evaluator or ruleset change remains a full replacement.
- A browser consultation timeout is ambiguous while its exact controller or submitted conversation remains recoverable; reattach the same session before classifying failure.
- Sanitizer capability requires compile, link, and runtime evidence; accepting `-fsanitize` at object compilation is insufficient.
- A sanitizer positive control passes only with an authenticated runtime and explicit diagnostic, never from exit status alone.
- No incident changes a frozen receipt. Any correction names the superseded claim and pins the original receipt hash.
- External build references are immutable inputs: compiler metadata written beside their sources is contamination even when production source bytes are unchanged.
- Redirected text stdin is part of the protocol artifact: encoding and preamble behavior must be explicit, probed, and hash-controlled before a frozen parity lease.
- A fixture failure counts only after its setup reaches the intended predicate; row names and nonzero exits cannot substitute for predicate-level evidence.
- Referee build and runtime environments pin Qt major version, C language mode, platform plugin variables and raw test streams before behavior conclusions are admitted.
- Browser conversation completion and controller finalization are separate evidence boundaries; a stored transport error cannot erase a separately authenticated complete response.
- Expected-red inventories include explicit green controls; newly written fixture code is not presumed to fail merely because production behavior has not changed.
- Container-level transfer code must compile against the pinned Qt major; API similarity across Qt containers is not evidence of member availability.
- A go barrier does not excuse manual digest transcription; tool hashes must be mechanically compared before the marker is written, with pre-go corrections recorded only as immutable addenda.
- Qt compile-time string macros accept literal tokens, not merely constant character pointers; portability builds must compile every newly introduced path before runtime evidence is possible.
- A build-system job limit does not automatically constrain nested code-generation pools; every promised thread ceiling must bind and verify AUTOGEN or equivalent internal parallelism explicitly.
- A functional process timeout is not a speed gate; derive it from authenticated Crazyhouse runtime observations and preserve raw outputs before classifying a timeout.
- Machine-readable conformance streams are raw-byte contracts; valid JSON and expected exits cannot excuse platform newline translation.
- PowerShell async task completions must not leak helper objects into structured result streams; suppress and type-check them before adding metadata.
- Test exit status is insufficient without a positive suite and row inventory from an explicitly captured logger.
- Computed PowerShell array elements must be parenthesized and the recorded argv must be reconciled with the actual child and its artifacts.
- Git revision expressions containing PowerShell metacharacters must be quoted and verified independently before they enter a receipt.
- A stored browser session is not current access evidence; the composer, selected model and submission state must be reauthenticated for every advisory boundary.
- Path normalization must not use regex replacement when literal paths are already canonical; empty or partial hash inventories carry no evidence.
- Optional resource sensors must fail independently and never suppress the complete ownership/admission snapshot.
- An outer functional timeout does not override referee-owned engine-start, ping, clock or quit deadlines; each deadline needs its own frozen evidence.
- Detached supervisors require a separately persisted launcher exit record; process absence and a completion file do not reconstruct an unobserved exit code.
- Path display conversion must use literal replacement, and every source inventory must reject zero-row output before any hash or line claim is admitted.
- Source authentication must batch Git object lookup and split independent repositories so a final-only serializer cannot cross the execution-yield boundary without evidence.
- A no-window MSYS build still needs a valid inherited stdin handle: redirect it and close it as EOF before any nested checksum or network-validation command runs.
- Known runner invariants are admission checks, not optional historical advice: every new MSYS build wrapper must mechanically prove EOF stdin and an exact `make net` validation before GO.
- Completion finalizers must normalize nullable external-process fields once and preserve a minimal fallback record even if rich inventory collection fails.
- A standard-control fixture is valid only for its pinned official source and network generation; upstream-sync controls supersede older comparators without rewriting them.
- Backend readiness and position readiness are distinct: every positive search-ready fixture must commit a position in the active route epoch.
- Empty-namespace accounting must explicitly normalize zero files to zero and reuse one preflighted helper in both capacity gates and completion emission.
- Multi-purpose fixture helper tuples must self-check every field against the source case before a formal green lease; a red compile cannot expose verifier runtime contradictions.
- Lazy incremental accounting must distinguish one materialization from its ancestor distance and from the number of sparse feature operations; forward-only reasoning is insufficient when the fixture authenticates undo materialization.
- Serialized tensor compatibility does not imply runtime-layout compatibility; every optimized evaluator path must prove the exact activation-to-weight lane mapping as well as final scalar parity.
- Logical nonzero activation count and serialized padded input dimension are distinct contracts; optimized loop bounds must use the latter whenever lane permutations span the padded block.
- A conservative sentinel must be audited at every caller by predicate polarity; callee-level labels cannot establish downstream pruning safety.
- Disabling a rule requires a semantic-consumer inventory across keys, TT score transforms, cutoff conditions and terminal code, not only result adjudication.
- Source-pattern verifiers must consistently consume their normalized representation; mixed raw/normalized scans require an explicit reason and a self-test.
- Blob authentication does not validate a document's commit pins; every 40-character object identity must also resolve to the intended Git object before the document is frozen.
- PowerShell identifiers that differ only by case are the same variable; identity scalars and parsed inventories need distinct semantic names plus type assertions.
- A native tool accepting one backslash-bearing Windows path does not prove all later path components safe; normalize archive/extraction arguments to forward slashes before GO.
- Redirected process runners must drain stdout and stderr before feeding stdin; timeout supervision must cover the complete bidirectional protocol.
- A declared child timeout is not active while the parent is synchronously blocked feeding stdin; controller preflight must prove a payload larger than pipe capacity through the exact asynchronous ordering.
- Multi-source MSVC commands cannot use implicit basename-derived objects when any source basenames collide; sanitizer admission requires a source-to-unique-object plan and separate compile invocations.
- MSVC ASan verifier admission must freeze and inspect the PE stack reserve; unsanitized success does not prove the default 1 MiB reserve is sanitizer-safe.
- A `/link` token inside a `cl.exe` response file is not evidence that following response entries reached the linker; link-only options need an authenticated command boundary and post-link header checks.
- A PowerShell function's empty array is no pipeline output, not a type-stable empty caller value; caller-side `@(...)` is mandatory before collection postconditions.
- Functional correctness processes need enough scheduler priority to make bounded progress; saturated-host timing remains inadmissible regardless of priority.
- Receipt producer and consumer schemas are executable contracts and require a no-target preview before GO.
- Sanitizer timeouts are operational ceilings, not scientific results; intermediate snapshots cannot override a later authenticated final transcript.
- Long scientific controllers must survive the initiating terminal session through a pre-admitted detached PID-bound supervisor.
- An evidence record is not sealed until every referenced path, byte count and digest passes a mechanical resolver.
- An `EVALFILE` assignment is not an evaluator-routing proof; admitted Crazyhouse builds must also authenticate the Makefile mode and emitted embed macros before runtime.
- A filename, archive name or provenance label cannot brand an engine protocol surface; the stable UCI identity must come from tracked source and the exact packaged executable must be the final strength-panel candidate.
- An independent verifier that fails to parse has executed zero assertions; preserve the gate artifacts and repeat with hash or file-based oracles that do not transport nested exact literals across shell layers.
- Windows Git fixture restoration must account for read-only object files and prove the temporary namespace is gone; a verified negative before cleanup is not a completed harness case.
- A direct harness pass does not authenticate Make's restricted child environment; Make-routed failures must retain the exact fixture, exit and streams before retry classification.
- Tracked-file equality does not make a clean export a Git repository; ancestry fixtures must receive an explicit, local, source-pinned Git authority and must never fall back to network access.
- A vanished diagnostic process is not a test result; preserve the yielded execution handle or require file-backed terminal receipts before classifying its outcome.
- A passing short-path diagnostic does not authenticate a longer formal namespace; freeze and verify the worst-case Windows checkout path before starting Git-heavy fixture matrices.
- A path budget derived from the first observed failure is not a worst-case proof; enumerate every frozen path component before authorizing the lease.
- A manually transcribed case list is not executable evidence; derive path-budget inputs from the tested harness AST and tested Git tree.
- Cross-tool process display names are not interchangeable evidence; freeze lifecycle assertions from the exact runtime API that will enforce them.
- A verifier's accepted argument combinations are part of the evidence schema; preregister exact argv and test mutually exclusive modes before an expensive formal build.
- A semantic line inventory and its serialized digest are separate contracts; delimiter bytes need an explicit hex/length self-test before freezing a derived checksum.
- A repository-name condition around write jobs does not neutralize unguarded matrix or reusable-workflow jobs; inherited release workflows need whole-file authority and target review.
- PowerShell launcher parameters are runtime-specific; bind priority to the captured owned PID and verify it before GO instead of assuming `Start-Process` exposes a priority option.
- Local gate qualification does not protect a future public workflow until that workflow invokes the exact verifier and carries an additive post-change digest receipt.
- A project virtual environment is not a controller-runtime authority; import every required lifecycle module with the exact pinned interpreter before start-receipt admission.
- A draft release cannot be reauthenticated through a published-by-tag assumption; bind every download to the exact authenticated release asset ID and verify its bytes before publication.
- Workflow structure checks must authenticate the pre-change job inventory instead of relying on a remembered job count.
- Never expand an abbreviated Git object ID from memory; resolve and validate the full object before freezing provenance.
- A clean working tree is not a public-clean history; scan both the candidate tree and every reachable commit subject before the first public push.
- A history scrub is not a self-contained public tree; resolve every tracked evidence reference from a clean clone and reject operator-local paths before publication.
